# HU-007: Alta del personal de la clínica

## Alcance

El módulo de Administración registra recepcionistas y administradores de clínicas afiliadas usando la misma colección `administradores` y la autenticación de HU-001. El modelo incorpora un DNI opcional para las cuentas del gimnasio y obligatorio, de ocho dígitos, para los roles de clínica. Se conservan las cuentas al desactivarlas.

La creación requiere nombres, apellidos, DNI, correo, rol de clínica y una clínica afiliada activa. El servicio normaliza el correo, indica si el correo o DNI está duplicado, crea la cuenta activa con contraseña no utilizable y solicita un enlace de recuperación de HU-001 para que el usuario defina su propia contraseña. El backend de correo se configura con `EMAIL_MODO`: en desarrollo puede escribir el enlace en la consola; en producción puede enviarlo por SMTP.

## Endpoints

- `GET /api/v1/personal-clinica/`: listado, opcionalmente filtrado por `clinica_id`.
- `POST /api/v1/personal-clinica/`: alta y solicitud del enlace de contraseña.
- `GET /api/v1/personal-clinica/{id}/`: detalle de una cuenta.
- `PATCH /api/v1/personal-clinica/{id}/`: edición de datos y clínica activa.
- `DELETE /api/v1/personal-clinica/{id}/`: desactivación lógica e invalidación de sesiones anteriores.

Solo una cuenta autenticada con rol `administrador_gimnasio` puede usar estas rutas. Las respuestas nunca incluyen el hash de la contraseña ni el token de recuperación.

## Interfaz React

La pestaña **Personal de clínica** permite dar de alta, editar, consultar y desactivar cuentas. Muestra errores de duplicidad por campo y ofrece únicamente clínicas activas para asignar personal nuevo. Si todavía no hay una sesión de Administración, indica que se trata de una vista de demostración y no guarda datos reales.

## Bloqueos de sesión

Una cuenta desactivada no puede iniciar sesión. Si la clínica vinculada está inactiva, su personal tampoco puede iniciar sesión, renovar el token ni usar uno ya emitido. Las cuentas y los registros históricos permanecen almacenados.
